# 패치 분석 자료

이 디렉터리에는 분석용 JSON과 날짜별 자료를 둔다. 행별 상세 CSV 23개는 [행별 대조표 안내](row-tables/README.md)와 `row-tables/`에 있다.

파일명은 `disk-{A-G}__{영역}__{자료종류}[__YYYY-MM-DD].확장자` 형식이다. 디스크 식별 문자는 A–G 대문자, 나머지 영문은 소문자로 쓴다. 항목 구분은 `__`, 항목 안 단어 구분은 `-`로 통일하며, Act 영역은 `act1`–`act5`로 쓴다. 문서와 CSV·JSON 안의 경로도 이 파일명을 사용한다.

이 자료는 날짜별 분석과 판본 비교용이다. 새 빌드의 raw 변경은 `../manual-build/`의 표에서 원본 바이트, 교체 바이트, 주소와 근거를 확인해 적용한다.
