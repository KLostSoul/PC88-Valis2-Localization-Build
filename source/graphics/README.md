# 그래픽 이미지

빌더가 Disk A 타이틀 자원과 Disk B 전투 자원을 인코딩할 때 사용하는 PNG 평면이 영역별 폴더에 있다.

| 폴더 | 자료 |
|---|---|
| [disk-A__mugen-title](disk-A__mugen-title/README.md) | 몽환전사 로고 3개 평면과 스크롤 글씨 |
| [disk-A__roman-ii](disk-A__roman-ii/README.md) | “II” 이미지 3개 평면 |
| [disk-A__valis-title](disk-A__valis-title/README.md) | “ヴァリス” 타이틀 3개 평면 |
| [disk-B__battle-cg](disk-B__battle-cg/README.md) | 전투 화면·HUD 3개 평면 |

평면별 파일과 크기는 하위 폴더 안내에 있다. 빌드의 이미지 배치는 source/manual-build/disk-A__title-cg.json 및 disk-B__battle-cg.json에 정의되어 있다.
