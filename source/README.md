# 빌드 자료

이 폴더에는 한글 빌드 입력 자료와 영역별 대조 자료가 있다.

| 폴더 | 내용 |
|---|---|
| [graphics](graphics/README.md) | Disk A 타이틀·문자 이미지와 Disk B 전투 CG PNG |
| [kanji](kanji/README.md) | 한글 글리프 558개의 코드·주소·비트맵 배정표 |
| [manual-build](manual-build/README.md) | 디스크별 적용 패치와 입력 원본 지문 |
| [patches](patches/README.md) | 영역별 분석 JSON과 행별 대조표 |
| [text-reference](text-reference/README.md) | 일본어 원문과 한국어 번역문 참조표 |

빌더는 manual-build의 패치 정의, kanji의 글리프표, graphics의 PNG를 사용한다. patches와 text-reference는 분석·문안 대조 자료다.
